# `01` — About

This repository is a collection of practical **Machine Learning and Artificial Intelligence projects** covering traditional machine learning, deep learning, computer vision, natural language processing, generative AI, retrieval-augmented generation, multi-agent systems, MLOps, audio intelligence, forecasting, and intelligent automation.

The projects are designed to explore how AI techniques can be transformed into **working software systems and real-world applications**.
